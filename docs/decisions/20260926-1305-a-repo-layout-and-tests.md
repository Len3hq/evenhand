# Repo layout (`src/`, `tests/`) and Vitest

- Status: accepted
- Date: 2026-09-26 · Owner: A

## Context

The spec's repo figure shows `src/` ("all code written during the window") and `tests/` ("your own test suite"). The plans said Jest. The Nest 12 generator ships Vitest and ES modules.

## Decision

- Workspaces `src/api`, `src/web`, `src/judging-engine`; end-to-end suites in root `tests/api`; unit tests next to the code.
- Prisma lives in `src/api/prisma` (not the repo root as TEAM-PLAN sketched): the Prisma CLI, config and client belong to the API package and its Docker image.
- **Vitest** everywhere, as generated by Nest 12. Jest and ts-jest do not support TypeScript 6 or ESM Nest cleanly.

## Consequences

Plans that mention Jest mean Vitest. Vitest (Oxc) emits decorator metadata, so Nest DI works in tests (verified).

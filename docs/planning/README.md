# Planning documents

These are the plans written before the build started, kept as they were written. [BUILD-PLAN.md](BUILD-PLAN.md) is the one the build followed; the others are the earlier drafts and checklists it was assembled from.

They record what was intended, not what exists. Where they differ from the code, the code and the documents at the root of the repository are right: [README.md](../../README.md) for what is built and verified, and [DECISIONS.md](../../DECISIONS.md) for each decision as it was actually made, including the ones that changed a plan (for example the stack, the normalization grid and the demo-token command).
